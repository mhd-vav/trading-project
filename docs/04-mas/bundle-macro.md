# Bundle 3 — Macro / Fundamental

- **Shared frame:** interest rates, central-bank policy, the economic calendar,
  intermarket relationships (bonds, FX, commodities, equities).
- **The single question the bundle answers:** *Does the fundamental backdrop support the
  move, or is it already priced in?*
- **Member agents (with the built-in opposition):**
  - **Monetary-policy** agent — argues the rate/policy path drives the move.
  - **Data-surprise** agent — argues it's the *surprise* vs expectations that matters, not
    the level.
  - **Intermarket referee** — checks cross-asset confirmation (e.g., does the bond move
    agree with the FX move?).
  - **Risk-sentiment referee** — classifies risk-on/risk-off.
- **Why the internal debate is logical:** "policy sets the path" vs "only surprises move
  price" is a real, long-standing debate in macro trading. The referees supply the
  cross-asset and sentiment context that resolves it for the current moment. This bundle's
  weight rises during news-heavy weeks (regime weighting in the orchestrator).
