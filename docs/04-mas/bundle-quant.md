# Bundle 6 — Quantitative / Statistical

- **Shared frame:** backtested, probabilistic/statistical evidence — seasonality,
  ML forecasts, regime classification, statistical edge estimates.
- **The single question the bundle answers:** *Is the edge robust, or is it overfit /
  regime-dependent?*
- **Member agents (with the built-in opposition):**
  - **Statistical-edge** agent — argues the backtested edge is real and tradeable.
  - **Overfit-skeptic (red-team)** agent — argues the edge is curve-fit and will fail
    out-of-sample.
  - **Seasonality referee** — supplies calendar/seasonal patterns.
  - **ML-forecast / regime-classifier referee** — supplies model-based forecasts and the
    current regime label.
- **Why the internal debate is logical:** "it backtested well" vs "it's overfit" is the
  single most important question in quantitative trading. The red-team agent exists
  specifically to prevent the system from trusting a fragile backtest. This is the
  intellectual-honesty bundle.
