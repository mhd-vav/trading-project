# Bundle 5 — On-Chain (crypto-only; dormant for Forex)

- **Shared frame:** exchange flows, holder behavior, on-chain valuation, network activity.
  Only meaningful for crypto assets.
- **The single question the bundle answers:** *Are strong hands accumulating or
  distributing?*
- **Member agents (with the built-in opposition):**
  - **Exchange-flow** agent — argues net outflows/inflows signal accumulation/distribution
    pressure (e.g., coins leaving exchanges = less sell pressure).
  - **Holder-accumulation** agent — argues long-term-holder behavior (supply metrics) is
    the cleaner signal.
- **Why the internal debate is logical:** exchange-flow and holder-behavior signals
  sometimes agree and sometimes diverge; the debate resolves which is the dominant force.
- **Dormancy:** this bundle is inactive for Forex. It activates only when the analyzed
  asset is a crypto. The orchestrator simply assigns it zero weight for non-crypto assets.
